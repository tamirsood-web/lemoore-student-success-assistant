Chat Window — Animated, Non-Modal

Floating chat interface with open/close and expand/collapse animations. Icons reference existing SVG assets from design-system/icons/. No page blocking. Header and footer fixed inside. Only content scrolls.

Controls

Open: entrance animation (opacity + translateY + scale).
Close: reverse exit animation, then hidden.
Expand: smooth width/height/position transition.
Collapse: returns to compact size.
All respect prefers-reduced-motion.

This is regular page content. Scroll, click, and interact — the chat window does not block anything.
